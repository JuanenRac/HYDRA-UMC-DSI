# Security Policy 🔒 (HYDRA-UMC-DSI)

## Reporting a Vulnerability

As a kiosk interface, the primary security concern is **Breaking out of the Fullscreen sandbox** or **Credential sniffing** from the local network.

Report privately to `electrohobby3d@gmail.com`.

## Credentials

The kiosk does not pre-populate administrator credentials. The operator enters
the credentials issued by the server bootstrap process and should clear them
before transferring or servicing the display.
